# 边界约定与容差说明

本组件只处理合成平面几何，不向真实矿卡下发路线。所有“允许的数值容差”集中在
`datapack/tolerances.py`，业务代码不内联魔数；本文件与该模块保持一致。

## 坐标变换链

- 目录条目是带 `version` 的有向边 `source -> target`，矩阵为二维齐次仿射
  `[a,b,tx,c,d,ty]`，目标点 `(ax+by+tx, cx+dy+ty)`。
- 单位（毫米/米）与轴方向（含反向轴）完全由矩阵编码。解析器只按折线声明的
  `crs` 与 `version` 在有向图上枚举**全部简单路径**，不读取坐标数值、不猜单位。
- 多条路径各自复合后的矩阵必须逐元素落在 `MATRIX_EPS=1e-9` 内一致，否则拒绝该条
  折线；无可达路径、近奇异矩阵（行列式绝对值 ≤ `SINGULAR_DET_EPS=1e-15`）同样拒绝。
- 源坐标系即 `map` 时唯一链为单位矩阵。被拒绝折线不产出任何片段，不影响其他折线。

## 区域与点归属

- 区域是含孔洞的简单多边形，外环与孔环均为隐式闭合，方向不参与语义。
- 外环边界与孔洞边界都属于**待核带（uncertain）**；外环内部扣除孔洞内部为确定
  内部（inside）；孔洞内部为排除区（excluded）；所有区域之外为 outside。
- 退化环（重合点、显式首尾闭合、零面积、有效边不足）、自交环、非相邻边接触环
  一律判非法。非法区域使对应 `map_version` 的折线全部拒绝，并在 `region_failures`
  中逐条说明原因；不影响其他地图版本。
- 孔必须完整落在外环内部且互不接触，否则区域非法。

## 切段与待核带

- 每条原线段在所有区域边界（外环 + 孔环）处精确切段，切点保留其在原线段上的
  参数 `t∈[0,1]` 与按 `t` 线性插值的时间；禁止用包围盒或首点状态替代整段裁切，
  一条折线可以多次进出同一区域。
- 段内定位误差半径取两端点 `error` 的较大者（资料约定 error 以地图单位米给出，
  不随源坐标系单位猜测而缩放）。
- 折线上距任一边界边距离 `<= 误差半径` 的部分单列为 `uncertain`，不强行归入任何
  区域；误差半径为 0 时，与边界共线的重叠部分仍属待核带（边界本身不是确定内部）。
- 距离平方按“点到边界边”的二次型计算，在边端点投影参数与二次顶点之间分段单调，
  用二分法（最多 `BISECT_LIMIT=60` 次）求距离等于半径的根。
- 区域重叠的**确定部分**按 `priority` 归属（数值小者优先，同级按区域 id 稳定
  排序）；待核带不参与优先级归属。共边只是相邻片的公共切点，长度不重复计算。
- 单点折线退化为零长片：内部/外部分别记 inside/outside，落在边界上记 uncertain。

## 容差配置

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `GEOMETRY_EPS` | `1e-8` | 几何绝对容差下限（米） |
| `GEOMETRY_REL_EPS` | `1e-10` | 按环包围盒尺度放缩的相对几何容差 |
| `MATRIX_EPS` | `1e-9` | 多变换链矩阵逐元素一致性 |
| `PARAM_EPS` | `1e-10` | 切段参数去重与区间合并 |
| `LENGTH_ABS_EPS` | `1e-7` | 长度/时间守恒绝对容差 |
| `LENGTH_REL_EPS` | `1e-9` | 守恒校验相对容差 |
| `SINGULAR_DET_EPS` | `1e-15` | 仿射矩阵近奇异阈值 |
| `BISECT_LIMIT` | `60` | 待核带根求解的二分上限 |

点在线上、环接触等判定使用 `geometry_eps(scale)=max(GEOMETRY_EPS,
scale*GEOMETRY_REL_EPS)`，`scale` 为环包围盒最大边长（至少为 1），避免大坐标下
固定绝对容差过松、小坐标下过紧。叉积判定再按边长量纲乘回尺度。

## 守恒验证器

每条被接受的折线附带 `verification`，任一检查失败则 `all_ok=false`：

1. `length_conservation`：全部片长之和等于归一后原折线长度，容差
   `max(LENGTH_ABS_EPS, 长度*LENGTH_REL_EPS)`；
2. `parameter_coverage`：每个原段的片从 `t=0` 铺满到 `t=1`，不重不漏，且所有原段
   都有片覆盖；
3. `time_conservation`：片时间差之和等于原折线首尾时间跨度；
4. `no_double_counting`：同一原段内片参数区间不得实质重叠（共边不重复计长）；
5. `valid_states`：状态只取 `inside / outside / excluded / uncertain`。
